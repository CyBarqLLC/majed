# majednamous.com — الموقع الشخصي لماجد ناموس

موقع ثابت (Static) خفيف: HTML + CSS + JS فقط. لا يحتاج Node ولا build tools للتشغيل.

## التشغيل محليًا
افتح `index.html` مباشرة، أو شغّل خادمًا بسيطًا:
```
python3 -m http.server 8000
```

## الرفع
ارفع محتويات المجلد كما هو إلى أي استضافة (Netlify / Vercel / cPanel / GitHub Pages).
لا يوجد build step. `build.py` أداة تطوير فقط ولا يلزم رفعها.

## البنية
```
index.html          الصفحة الرئيسية (عربي)
contact.html        صفحة التواصل (عربي)
en/index.html       Home (English)
en/contact.html     Contact (English)
assets/css/site.css نظام التصميم كاملًا (tokens + layout)
assets/js/site.js   القائمة + الحركات + السنة الديناميكية
assets/fonts/       majed-arabic (JH Naskh) + Thmanyah Serif Display — محمّلة محليًا
assets/img/         الصور محسّنة WebP + JPG fallback بمقاسين
assets/svg/         الشعارات (تُدرج inline لتتلوّن مع الخلفية)
build.py            مولّد الصفحات — كل النصوص والبيانات بداخله
robots.txt, sitemap.xml
```

## تعديل المحتوى
كل النصوص وبيانات التواصل والروابط والأعمال موجودة في **`build.py`** فقط:

- `SITE` — الهاتف، واتساب، البريد، رابط أثر، رابط المقابلة.
- `WORKS` — قائمة الأعمال (اسم الصورة + السنة + النص البديل بالعربية والإنجليزية).
- `AR` / `EN` — كل نصوص الموقع بالّلغتين.

بعد أي تعديل:
```
python3 build.py
```
تُعاد كتابة الصفحات الأربع تلقائيًا.

## إضافة عمل جديد
1. جهّز الصورة مربعة وصدّرها باسم `work-YYYY-1000.webp` و`work-YYYY-640.webp` و`work-YYYY-1000.jpg` داخل `assets/img/`.
2. أضف عنصرًا جديدًا في `WORKS` داخل `build.py`.
3. `python3 build.py`.

## نبرة النصوص
كل نصوص الموقع بضمير المتكلّم «أنا» — ماجد يتحدث عن نفسه، لا أحد يتحدث عنه.
حافظ على هذا عند أي تعديل في `AR` / `EN` داخل `build.py`.

## التفاعل والحركة
- الهيرو: فسيفساء من الأعمال في ستة صفوف تنساب أفقيًا باتجاهات متعاكسة، على مستوى مائل، وتتحرّك قليلًا مع مؤشر الفأرة.
- المعرض: شبكة فسيفسائية بأحجام متفاوتة؛ كل بلاطة مائلة قليلًا وتلتفّ مع سرعة التمرير، وتستوي وترتفع عند المرور عليها.
- خط تقدّم رفيع أسفل الناف بار.
- كل ذلك يعمل عبر `requestAnimationFrame` واحد يكتب متغيّرات CSS (`--sv`, `--px`, `--py`, `--prog`)، والـCSS هو من يرسم. بلا أي مكتبة.
- كل الحركة تتوقف تمامًا مع `prefers-reduced-motion`.

## قاعدة الخطوط (مهمة)
- **majed arabic** يُستخدم للعناوين العربية فقط: اسم الهيرو، عناوين الأقسام، عنوان أثر، عنوان صفحة التواصل.
- **Thmanyah Light** يُستخدم لكل ما عدا ذلك: الفقرات، الوصف تحت العنوان، الميتاداتا، القائمة، الفوتر، وكل النص اللاتيني.
- تنبيه في خط majed arabic: **الياء في آخر الكلمة تُرسم منفصلة** عن الحرف قبلها. لذلك لا تضع في العناوين العربية كلمة تنتهي بـ«ي» (مثل «الوقفي»، «التي»، «في») — ضعها في الوصف أو الميتاداتا حيث يعمل خط ثمانية بوصل سليم. هذه القاعدة موثّقة أيضًا أعلى قسم المحتوى في `build.py`.

## ملاحظات تقنية
- Mobile first، بدون أي horizontal overflow، الشبكة تتدرّج: عمود ← عمودان ← عمودان مع إزاحة تحريرية.
- الخطوط بصيغة WOFF محمّلة محليًا: majed-arabic ‏165KB، وThmanyah ‏95–102KB لكل وزن (Light/Regular/Medium).
- الخط العربي أحادي الوزن، لذلك التدرّج الطباعي يعتمد على الحجم والمسافات لا على الأوزان.
- لا توجد أي إيموجي أو أيقونات جاهزة في الموقع؛ السهم الوحيد مرسوم inline SVG.
- `prefers-reduced-motion` محترم بالكامل.
- SEO: عنوان ووصف وOpenGraph لكل صفحة، `hreflang` بين العربية والإنجليزية، canonical، sitemap.
- غيّر `BASE_URL` في `build.py` إذا اختلف الدومين.
